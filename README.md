# AIAGENT_APM — Agentic Process Management

Persistent, agentic orchestration layer that sits above existing business tools
(email, calendar, spreadsheets, ERP/CRM, ...), maintains process state and
context over time, and lets a person interact with the process in natural
language instead of operating each tool by hand.

> "Don't operate the tools. Talk to the business."

Built for the TechIreland National AI Challenge 2026 by team **Agentic
Process Lab (APL)**.

This branch (`claude/hello-mt20cg`) is the integration branch for the MVP.
Each build phase lands here as its own reviewed pull request — see
`docs/roadmap.md` (added in the scaffolding PR) for the phase breakdown.
